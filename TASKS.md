# План работ

Переход к следующему этапу — только после одобрения пользователя. Пункты «Проверки» отмечаются после фактического прогона.

## Этап 1. MVP-прототип

- [x] Проект Godot 4.7, gl_compatibility, viewport 400x224, stretch canvas_items/keep, ландшафтная ориентация
- [x] Input map: движение (WASD/стрелки), fire, pause, restart, confirm
- [x] Уровень из текстового файла (`LevelData`, 26x26 клеток), `levels/level_01.txt`
- [x] `Battlefield`: сетка, кирпич (разрушаемый), сталь, база 2x2, границы карты
- [x] Танк игрока: движение по сетке 8 px, 4 направления, стрельба (1 пуля, cooldown)
- [x] Пули: sub-step движение, разрушение кирпича, остановка о сталь, столкновение пуль врагов и игрока
- [x] Враг `basic` (TankStats), простой ИИ: блуждание, стрельба, пробивание кирпича
- [x] Спавнер врагов: очередь из уровня, `max_active`, точки появления по кругу
- [x] База: уничтожение пулей = поражение
- [x] Жизни (3), респаун игрока, щит после респауна
- [x] Условия победы/поражения, экран результата, рестарт, следующий этап
- [x] HUD: этап, враги, жизни, убито; пауза
- [x] Процедурная графика (_draw), эффект взрыва
- [x] Unit-тесты (`tests/`, запуск `res://tests/test_runner.gd`)
- [x] `tools/check.sh`
- [x] Документация: README, AGENTS, CLAUDE, TASKS, PROGRESS, docs/*

Критерии приёмки: см. `docs/ACCEPTANCE_CRITERIA.md`. Игра запускается, уровень проходится до победы и поражения, рестарт работает, тесты и smoke-прогон проходят.

Проверки:
- [x] `bash tools/check.sh` завершается с кодом 0
- [x] Юнит-тесты проходят (65/65)
- [x] Smoke-прогон 900 кадров без ошибок скрипта
- [x] Рендер 600 кадров через Movie Maker (`--write-movie`), кадры проверены визуально
- [ ] Ручной запуск `godot --path .`: управление, победа, поражение, рестарт

## Этап 2. Игровые системы

- [ ] 3 типа врагов (разные скорость, HP, cooldown, скорость и сила пули) через `TankStats`
- [ ] Улучшенный ИИ (поиск пути к базе / игроку, реакция на препятствия)
- [ ] Система жизней: доработка, очки/счёт
- [ ] Бонусы: доп. жизнь, неуязвимость, улучшение оружия, защита базы
- [ ] Вода (непроходима для танков, проходима для пуль) и лес (рисуется над танками, не блокирует)
- [ ] Система урона: HP врагов > 1, `bullet_power` (сталь пробивается усиленным оружием)
- [ ] Дополнительные unit-тесты на новые системы

Критерии приёмки: все перечисленные механики работают в уровне; каждая новая система покрыта тестами; предыдущие тесты проходят.

Проверки:
- [ ] `bash tools/check.sh` проходит
