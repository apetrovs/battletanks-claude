# Игровой дизайн (состояние этапа 1)

Значения взяты из `data/tanks/*.tres` и скриптов. Единицы: пиксели базового разрешения (400x224), секунды.

## Поле и представление

- Карта 26x26 клеток по 8 px = 208x208 px. Смещение в сцене: (96, 8); слева и справа панели HUD.
- Танк 16x16 px (2x2 клетки). Пуля 4x4 px.

## Клетки

| Клетка | Поведение |
|---|---|
| Пусто | проходимо |
| Кирпич | блокирует танки и пули; разрушается пулей |
| Сталь | блокирует танки и пули; пулей не разрушается (`bullet_power` пока не учитывается при ударе) |
| База (2x2) | блокирует танки и пули; попадание любой пули (включая пулю игрока) уничтожает базу = поражение |
| Граница карты | танк не выходит за карту; пуля на границе исчезает |

Разрушение кирпича: пуля удаляет клетки в одном ряду/столбце на переднем крае, полосой шириной 14 px (IMPACT_HALF_WIDTH = 7 в каждую сторону от центра пули) поперёк полёта, т. е. до двух клеток за выстрел (иногда 2-3 при смещении относительно сетки).

## Танки

| Параметр | Игрок (`player.tres`) | Враг basic (`enemy_basic.tres`) |
|---|---|---|
| speed | 48 px/с | 32 px/с |
| max_hp | 1 | 1 |
| fire_cooldown | 0.25 с | 0.5 с |
| bullet_speed | 170 px/с | 110 px/с |
| bullet_power | 1 | 1 |
| max_bullets | 1 | 1 |
| цвет | жёлтый | серый |

- Выстрел возможен, если не закончилась перезарядка и `active_bullets < max_bullets` (на экране не более одной своей пули).
- Пуля стартует на 6 px впереди центра танка.
- Поворот: направление меняется сразу. При повороте на 90° танк выравнивается по сетке 8 px по поперечной оси (если там не мешает другой танк), чтобы проходить в коридоры шириной 2 клетки.
- Движение останавливается вплотную к препятствию. Танки блокируют друг друга; уже существующее пересечение (например, после респауна) можно только покинуть.
- Появление (spawn phase): 0.6 с мигающий маркер, танк неуязвим и не действует.

## Пули

- Движутся подшагами по 2 px, чтобы не пролетать сквозь клетки.
- Пуля игрока и пуля врага, столкнувшись, уничтожают друг друга. Пули одной команды друг с другом не взаимодействуют.
- Пуля повреждает только танки противоположной команды (дружественного огня нет, пуля врага проходит сквозь других врагов).
- Каждое попадание в танк наносит `bullet_power` урона; при hp <= 0 танк уничтожается. Неуязвимый (щит или фаза появления) танк урон не получает.
- Пуля, попавшая в танк, вылетевшая за карту или остановленная терраном, исчезает; визуальный взрыв маленький.

## Игрок

- Жизней: 3 (`START_LIVES`).
- При гибели жизнь -1. Если жизни остались, респаун через 1.0 с (`RESPAWN_DELAY`) на точке P (ждёт, пока область свободна), щит 3.0 с (`RESPAWN_SHIELD`); щит также действует в начале раунда. Щит рисуется мигающей окружностью.
- Если жизней нет — поражение.
- При выборе направления несколько удерживаемых клавиш: если текущее направление всё ещё удерживается, танк продолжает ехать в нём, иначе берётся первое из порядка вверх, вниз, влево, вправо.

## Враги и спавнер

- Очередь типов задаётся в заголовке уровня (`enemies=`), в level_01: 8 врагов `basic`; `max_active=3`.
- Первый враг появляется через 0.5 с после начала раунда, затем интервал 2.5 с между появлениями (`SPAWN_INTERVAL`). Враг появляется, только если число живых < `max_active` и область точки спавна свободна.
- Точки спавна перебираются по кругу, начиная со следующей после последней использованной; если точка занята, пробуется следующая.
- Враги появляются лицом вниз.

### ИИ врага (`EnemyTank`)

- Блуждание: направление выбирается случайно с весами; базовый вес 1.0, +3.0 за движение по вертикали в сторону цели и +2.0 за движение по горизонтали в сторону цели (порог 4 px). Цель: база с вероятностью 0.65, иначе игрок (если игрок жив, иначе база).
- Смена направления через случайные 1.0-3.0 с или при отсутствии направления.
- Блокировка: если путь заблокирован дольше 0.2 с, при кирпиче впереди с вероятностью 0.6 враг стреляет (прорыть путь), иначе меняет направление (не на текущее).
- Стрельба: по таймеру каждые 0.7-1.8 с, а также когда база или игрок (если он не в фазе появления) находится на линии огня (допуск 6 px, цель впереди по направлению).
- Каждый враг имеет собственный RNG, сидируемый от RNG игры (детерминизм при заданном seed).

## Конец раунда

- Победа: очередь пуста и нет живых врагов.
- Поражение: уничтожена база (мгновенно) или игрок потерял последнюю жизнь.
- После конца раунда симуляция продолжается ещё 1.5 с (`END_DELAY`), затем экран результата принимает ввод.
- Enter на победе — следующий уровень (циклически по `Game.LEVELS`; сейчас уровень один), Enter или R на поражении — повтор. R работает в любой момент.
- Пауза (Esc) доступна только во время игры (PLAYING).

## HUD

Левая панель: название и подсказки управления. Правая: название уровня, иконки оставшихся врагов (очередь + живые), жизни, убито. Оверлей: PAUSED, STAGE CLEAR, GAME OVER.
