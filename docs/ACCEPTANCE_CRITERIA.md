# Критерии приёмки этапа 1

Способ проверки: **Авто** — unit-тест или smoke-прогон (`bash tools/check.sh`); **Ручн.** — проверка при запуске `godot --path .`. Статус проверок фиксируется в `PROGRESS.md` и `TASKS.md`.

| № | Критерий | Проверка |
|---|---|---|
| 1 | Проект открывается и импортируется в Godot 4.7.x без ошибок | Авто: импорт в `tools/check.sh` |
| 2 | Игра запускается, главная сцена `scenes/main.tscn`, 400x224, окно 1200x672 | Авто: smoke-прогон 900 кадров; Ручн.: внешний вид |
| 3 | Уровень загружается из `levels/level_01.txt`; невалидные уровни дают ошибки | Авто: тесты `LevelData` (валидный и невалидные примеры) |
| 4 | Игрок ездит по 4 направлениям, упирается в стены и границы, не проходит через кирпич и сталь | Авто: тесты движения; Ручн.: WASD/стрелки |
| 5 | Выравнивание по сетке 8 px при повороте на 90°, проход в коридоры 2 клетки | Авто: тест поворота |
| 6 | Игрок стреляет; перезарядка и лимит пуль соблюдаются | Авто: тест `try_fire`; Ручн.: Space |
| 7 | Пуля разрушает кирпич и не разрушает сталь; пуля не туннелирует на высокой скорости | Авто: тесты `Battlefield` / `Bullet` |
| 8 | Попадание в врага уничтожает его, счётчик убийств растёт | Авто: тест |
| 9 | Враги появляются по спавнеру (первый через 0.5 с, интервал 2.5 с, не больше `max_active`) | Авто: тесты `EnemySpawner` |
| 10 | Враги двигаются, стреляют, не застревают постоянно | Авто: smoke-прогон со seed; Ручн.: наблюдение |
| 11 | Попадание в базу = поражение | Авто: тест |
| 12 | Игрок: 3 жизни, респаун через 1.0 с, щит 3.0 с, потеря всех жизней = поражение | Авто: тесты |
| 13 | Победа при уничтожении всей очереди врагов | Авто: тест (ускоренный прогон) |
| 14 | Экран результата: Enter — следующий этап / повтор, R — рестарт, Esc — пауза | Ручн. |
| 15 | HUD показывает этап, врагов, жизни, убито | Ручн. |
| 16 | Симуляция детерминирована при одном seed | Авто: тест |
| 17 | Нет ошибок скриптов за 900 кадров headless | Авто: smoke-прогон |
| 18 | Документация (README, AGENTS, CLAUDE, TASKS, PROGRESS, docs/*) соответствует коду | Ручн.: ревью |

Примечание: конкретный набор автотестов определяется каталогом `tests/`; пункты, для которых теста нет, проверяются вручную.
